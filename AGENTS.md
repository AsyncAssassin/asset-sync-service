# Работа с GitHub

- В этом проекте обращаться к GitHub только через CLI `gh` под аккаунтом `AsyncAssassin`.
- Перед обращением к репозиторию проверять аккаунт командой `gh api user --jq .login`. Если активен другой аккаунт, использовать `gh auth switch --hostname github.com --user AsyncAssassin` и повторить проверку.
- Не использовать GitHub-коннекторы или учётные данные других аккаунтов для этого проекта. Учитывать, что переменные `GH_TOKEN` и `GITHUB_TOKEN` могут переопределять аккаунт `gh`.
